# Bachelor of Theology — handbook production plan

**Status: internal. Not published. No route renders this file.**

Working notes for building the full B.Th. handbook. Everything here is either
advice to the university or a record of what has not yet been written — both
categories that must not appear on the prospectus as though settled.

---

## 1. What is published, and what is not

The B.Th. page at `/bachelor-of-theology` currently carries everything the
university has actually specified:

| Supplied | Published |
|---|---|
| Qualification, faculty, duration, 180 ECTS, study modes, NQF level | Yes |
| Programme description (6 paragraphs) | Yes, verbatim |
| Philosophy of the programme (4 paragraphs) | Yes, verbatim |
| Ten programme aims | Yes, verbatim |
| Ten learning outcomes | Yes, verbatim |
| 180-ECTS structure table (6 semesters × 30) | Yes |
| Year One Semester One — BTH101–106, codes and ECTS | Yes |
| BTH101 unit list (15 units) | Yes |
| BTH102–106 indicative contents | Yes |
| Final year: thesis, internship, oral defence | Yes |
| Career opportunities, progression routes | Yes |

**Not supplied, therefore not published: 30 of the 36 courses.**

Semester Two and Years Two and Three are described only as counts — "six more
fully developed courses", "twelve fully developed courses" — with no titles,
codes, credit values or unit outlines. These have deliberately **not** been
invented. The structure table marks those five semesters "In development" and
the page carries a note directing enquiries to the admissions office.

This matters for accreditation. A published curriculum that lists courses the
faculty has not validated is worse than a published curriculum that is honest
about its stage.

## 2. Handbook target (for reference, not publication)

- 36 fully developed courses
- 180 ECTS
- 220–300 pages, roughly 120,000 words
- Per course: description, objectives, learning outcomes, unit-by-unit content,
  assessment strategy, recommended readings

Per the site-wide visibility rule, when those courses are written:
**course codes, titles, unit outlines, objectives, outcomes and assessment
methods are public; recommended reading lists go to the portal.**

Semester One table. BTH104 is published as "Church History I", not "Church
History I: Apostolic to Medieval Church". Confirm which form is authoritative.

## 4. RECOMMENDATION — courses to add (awaiting decision)

Suggested for a modern B.Th., not yet part of the published curriculum:

Biblical Hebrew · New Testament Greek · Biblical Archaeology · Christian
Apologetics · Philosophy of Religion · African Theology · Contextual Theology ·
World Religions · Biblical Ethics · Pastoral Counseling

Several of these already appear as themes in the published programme
description (African Theology, Contextual Theology, Christian Ethics,
Missiology, Pastoral Care, Christian Education), so the description currently
promises breadth the course list has not yet been written to deliver. Closing
that gap should be the priority when Semester Two is drafted.
